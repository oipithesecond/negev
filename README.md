# Discord Activity Tracker Bot

A Discord bot that tracks user activity via Rich Presence and sends real-time updates to a user-specified channel, keeping your server informed and engaged.

## Features
- Tracks user activity using Discord's Rich Presence.
- Monitors games and other activities in real-time.
- Sends customizable alerts to a designated text channel.

## Usage

### Slash Commands
- `/alerts-channel <channel>`: Specify the channel where activity alerts will be sent.
- `/ping`: Check if the bot is online.

### Manual Testing
- Send the message `negev` in any text channel where the bot is active to test basic functionality.

## Bot Permissions
Ensure the bot has the following permissions:
- Manage Channels
- Send Messages
- Read Message History
- Use Slash Commands
